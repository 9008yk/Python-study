# 第一周：基础语法入门

原则：每个知识点都自己敲一遍，不要只看不写。

## 每日任务

- [x] Day 1：运行 `hello.py`，理解 `print()` 和字符串
- [x] Day 2：变量、整数、浮点数、字符串拼接、f-string
- [x] Day 3：`if / elif / else`，写一个简单的成绩判断
- [x] Day 4：`for` 和 `while` 循环，写一个 1 到 100 求和
- [x] Day 5：列表和字典，完成 `exercises.py` 里的练习
- [x] Day 6：函数定义、参数、返回值
- [ ] Day 7：综合小任务，做一个能保存文件的“待办清单”

## 完成标准

- 能不看资料写出变量、条件、循环、列表、字典、函数的示例
- 能读懂常见报错信息，比如 `NameError`、`TypeError`、`IndentationError`
- 能通过 `python 文件名.py` 运行自己的代码
